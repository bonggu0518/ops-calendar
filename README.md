# 생산운영본부 팀별 주요 일정 캘린더

각 팀이 웹에서 미팅·출장·외근·교육·연차·반차·병가 등을 등록하면, 본부 전체 일정을 월간 달력 한 화면에서 볼 수 있는 사이트입니다.

- 화면: 깃허브 페이지(GitHub Pages)에 올린 `index.html`
- 데이터: 구글 시트 (`일정` 시트에 한 줄씩 쌓임 → 엑셀로 내려받기 가능)
- 접근: 본부 공용 비밀번호 1개 (비밀번호가 없으면 일정 데이터를 받아올 수 없음)

```
index.html            ← 캘린더 화면 (깃허브에 올리는 파일)
apps-script/Code.gs   ← 구글 시트에 붙여넣는 서버 코드
```

---

## 1단계. 구글 시트 만들기 (약 10분)

1. 구글 드라이브에서 **새 스프레드시트**를 만들고 이름을 `생산운영본부 일정`으로 바꿉니다.
2. 메뉴 **확장 프로그램 → Apps Script** 를 엽니다.
3. 기본으로 있는 코드를 모두 지우고 `apps-script/Code.gs` 내용을 통째로 붙여넣습니다.
4. 맨 위 `INITIAL_PASSWORD = 'change-me-1234'` 를 **본부 공용 비밀번호**로 바꾸고 저장(Ctrl+S)합니다.
5. 상단 함수 목록에서 **setup** 을 고르고 **실행** → 권한 요청이 뜨면 본인 계정으로 승인합니다.
   - "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → (프로젝트 이름)(으)로 이동** 을 누르면 됩니다. 본인이 만든 스크립트라 정상입니다.
6. 시트로 돌아가면 `일정`, `설정` 시트가 생겨 있습니다.
   - `설정` 시트 A열에 **실제 본부 팀 이름**으로 고쳐 주세요. (B열 색상은 비워도 자동 지정)
   - D열 `구분` 목록(미팅, 출장, 연차 …)도 필요하면 추가·삭제합니다.

## 2단계. 웹 앱으로 배포

1. Apps Script 화면 오른쪽 위 **배포 → 새 배포**
2. 톱니바퀴에서 유형 **웹 앱** 선택
3. **실행 사용자: 나**, **액세스 권한: 모든 사용자** 로 설정 → **배포**
4. 나오는 **웹 앱 URL** (`https://script.google.com/macros/s/…/exec`)을 복사합니다.

> "모든 사용자"로 열어도, 요청마다 비밀번호를 확인하므로 비밀번호 없이는 일정을 볼 수도 쓸 수도 없습니다.

## 3단계. 사이트에 주소 넣기

`index.html` 을 메모장으로 열고 아래 줄을 찾아 복사한 URL을 넣습니다.

```js
const API_URL = "https://script.google.com/macros/s/……/exec";
```

비워두면 예시 일정으로 동작하는 **미리보기 모드**입니다.

## 4단계. 깃허브에 올리기

1. github.com → 오른쪽 위 **+ → New repository**
   - 이름 예: `ops-calendar`
   - **Public** 선택 (무료 계정은 Public 저장소만 Pages 사용 가능. 코드만 공개되고, 일정 데이터는 구글 시트에 있어 공개되지 않습니다.)
2. 만든 저장소에서 **Add file → Upload files** → `index.html`, `README.md`, `apps-script` 폴더를 끌어다 놓고 **Commit changes**
3. 저장소 **Settings → Pages** → Source: **Deploy from a branch**, Branch: **main / (root)** → Save
4. 1~2분 뒤 `https://<계정명>.github.io/ops-calendar/` 로 접속됩니다. 이 주소와 비밀번호를 팀장님들께 공유하면 끝입니다.

## 운영 메모

| 하고 싶은 일 | 방법 | 재배포 필요 |
|---|---|---|
| 팀·구분 목록 변경 | `설정` 시트 수정 | 아니요 |
| 비밀번호 변경 | `Code.gs`의 `INITIAL_PASSWORD` 수정 → `setPassword` 실행 | 아니요 |
| 잘못 들어간 일정 정리 | `일정` 시트에서 직접 수정·행 삭제 | 아니요 |
| 일정 엑셀로 받기 | 시트에서 **파일 → 다운로드 → Excel** | — |
| `Code.gs` 코드 수정 | 수정 후 **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포** (URL 유지) | 예 |
| 공휴일 추가(2028년 등) | `index.html`의 `HOLIDAYS` 목록에 추가 후 깃허브에 다시 올리기 | — |

- 구글 시트 자체는 본인(관리자)만 열 수 있게 두세요. 시트 공유 링크를 돌리면 비밀번호 없이 내용이 보입니다.
- 연차·병가는 개인 정보 성격이 있으니, 내용 칸에는 사유를 적지 않고 `연차`처럼 구분만 남기는 기준을 권장합니다.
- 화면 기능: 월간/목록 보기, 팀·구분별 표시 켜고 끄기, 오늘 휴가·출장 인원 요약, 날짜 칸 `+` 또는 더블클릭으로 바로 등록, 일정 클릭 시 수정·삭제.
